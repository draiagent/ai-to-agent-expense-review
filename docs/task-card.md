# 長照財務核銷任務圖卡（VAC）

## 任務

Agent 負責整理單據、比對紀錄和準備報表草稿。承辦人負責校對、判斷差異及核定。每批按月份管理，重跑時比對原有編號及來源，避免同一筆重複列入。

| 步驟 | 執行方式 | 交付 |
| --- | --- | --- |
| 收件解析 | 拆分同頁多張單據，保留原圖、來源頁碼與位置 | 附件索引 |
| 憑證辨識 | 用可用的圖片辨識工具讀取日期、統編與票面金額。模糊欄位留空並標記 | 憑證欄位 |
| 內帳整理 | 逐筆編號，登錄用途與票面金額，連回原圖 | 核銷明細草稿 |
| 付款對帳 | 依佐證分別登錄商家實付與公司撥款。可能重複或有多個配對時列待確認 | 付款比對結果 |
| 核銷審核 | Agent 列出差異和缺件，人員對照原始資料並記錄核定金額及理由 | 人工審核紀錄 |
| 報表定稿 | 以人工核定紀錄彙整月報，核對總計與明細，並連回附件 | 月報、核銷明細、附件索引 |

## 欄位與驗收

明細至少包括編號、日期、統編、用途、票面金額、商家實付、公司撥款、核定金額、附件索引及審核狀態。付款與撥款如有多筆，保留各筆佐證和合計。

每筆都能由編號找到原圖，待確認項能看到缺少什麼，未核定金額不納入定稿合計。重跑時保留人工審核紀錄，來源有變動的項目重新送審。

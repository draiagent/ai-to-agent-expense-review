# 長照財務核銷｜同一張發票，為什麼要抄好幾次？

第一次接手長照核銷，桌上放著一疊發票，電腦裡開著好幾份 Excel。光是弄懂「這張發票要填在哪一欄？」就花了不少時間。

好不容易把日期、統編和金額輸入表格，才發現另一份表還要再填一次。月底對帳時，有一筆找不到付款紀錄，又得翻資料、問同事。有時候整理了一整個下午，真正要確認的那幾筆，還沒來得及看。

## 先把做法寫成一張任務圖卡

我把長照核銷拆成六步：**整理收到的單據 → 讀出發票資料 → 逐筆登錄 → 比對付款紀錄 → 人員審核 → 完成報表。**

圖卡就像一份交接清單，寫清楚每一步要看什麼資料、要填哪些欄位，遇到問題怎麼處理。比如一張掃描圖裡有兩張收據，Agent 就分開整理、各編一個號碼，並保留原圖。遇到金額看不清楚，或是找不到付款紀錄，就在那一筆旁邊註記「待確認」。

## Agent 先整理，最後由人核對

行政同仁打開表格，就能看到每筆資料對應哪張單據、哪些地方還要查。接著由人員對照原始單據和付款紀錄，確認金額與用途，核定可報銷的金額，再把月報和明細定稿。

下次換新人接手，手上就有一張照著走的圖卡，也知道遇到哪種情況要停下來問。**你手上有沒有一件每個月都要做、同一份資料卻得抄好幾次的工作？** 那就很適合拿來試做第一張任務圖卡。
